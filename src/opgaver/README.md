# Opgaver

Lav opgaverne i rækkefølge. Start i `nemme`, og gå videre til `svære`, når du kan forklare din løsning med dine egne ord.

- `nemme/`: én funktion ad gangen
- `svære/`: flere funktioner kombineret i samme opgave
- `../tests/`: små eksempler, der viser det forventede resultat

Regel: prøv selv først. Brug derefter `tests` til at kontrollere resultatet.
