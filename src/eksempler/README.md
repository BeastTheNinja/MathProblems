# Læseeksempler

Disse filer er facit-lignende eksempler med forklarende kommentarer.

Læs dem efter du har prøvet en opgave selv. Følg altid samme rækkefølge:

1. Hvad er inputtet?
2. Hvilke mellemtrin skal der ske?
3. Hvad skal funktionen returnere?

- `01-nem.ts`: én Math-funktion
- `02-mellem.ts`: flere trin med map og reduce
- `03-svaer.ts`: flere funktioner kombineret
- `04-ekstrem.ts`: del et større problem op i mindre dele
