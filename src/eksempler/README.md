# Læseeksempler

Disse filer er facit-lignende eksempler med forklarende kommentarer.

## Grundfunktioner

Læs disse ekstra grundige eksempler, når du øver de fem vigtigste funktioner:

1. `09-floor-grundigt.ts` - rund ned
2. `10-ceil-grundigt.ts` - rund op
3. `11-round-grundigt.ts` - rund til nærmeste heltal
4. `12-random-grundigt.ts` - lav tilfældige heltal
5. `13-reduce-grundigt.ts` - saml mange tal til ét resultat

Læs ét eksempel, luk filen, og prøv derefter en opgave uden inline suggestions.

Læs dem efter du har prøvet en opgave selv. Følg altid samme rækkefølge:

1. Hvad er inputtet?
2. Hvilke mellemtrin skal der ske?
3. Hvad skal funktionen returnere?

- `01-nem.ts`: én Math-funktion
- `02-mellem.ts`: flere trin med map og reduce
- `03-svaer.ts`: flere funktioner kombineret
- `04-ekstrem.ts`: del et større problem op i mindre dele
